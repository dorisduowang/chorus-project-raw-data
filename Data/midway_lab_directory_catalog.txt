   ```bash

   # Quick check for catalog updates needed

   JEVANS="/project/jevans"
   CATALOG="$JEVANS/lab_directory_catalog.txt"

   CURRENT_COUNT=$(cd $JEVANS && ls -d */ 2>/dev/null | wc -l)

   echo "Cataloged directories: $CATALOG_COUNT"

   if [ $CURRENT_COUNT -gt $CATALOG_COUNT ]; then
       echo "⚠️  NEW DIRECTORIES DETECTED: $((CURRENT_COUNT - CATALOG_COUNT)) new"
       echo "New directories:"
       ls -dt $JEVANS/*/ | head -$((CURRENT_COUNT - CATALOG_COUNT))

       echo "✓ Catalog is up to date"
   fi

   # Check for recent large additions (>10GB in last 30 days)
   echo -e "\n📊 Large recent additions (>10GB, last 30 days):"
   find $JEVANS -maxdepth 1 -type d -mtime -30 -exec du -sh {} \; | \
       awk '$1 ~ /[0-9]+G/ && $1+0 >= 10 {print}'
   ```

   **VALUABLE DATA** - Use when directory contains:
   - Major datasets (>10GB typically)
   - Irreproducible computations (esposito patent matrices)
   - Clean, processed data ready for reuse
   - Current snapshots of databases (OpenAlex, Semantic Scholar)
   - Well-documented research outputs

   **ACTIVE RESEARCH** - Use when:
   - Recent activity (within last 6 months)
   - Multiple project subdirectories
   - Clean code structure
   - Active development indicators (recent commits, batch jobs)

   Avoid marking as valuable:
   - Old coursework or thesis projects (unless exceptional)
   - Spaghetti code without documentation
   - Abandoned projects with no clear outputs
   - Temporary workspaces
   - Downloaded models that can be re-obtained
